# ExploreLanka 🇱🇰

### Offline Sri Lankan Travel Guide

ExploreLanka is a React Native mobile application designed to help users discover beautiful tourist destinations across Sri Lanka.

The application provides destination information and search functionality using locally stored data. Users can explore destinations even without an internet connection.

## ✨ Features

- View popular tourist destinations in Sri Lanka.
- Search destinations by name, district, or category.
- View destination details.
- Explore destinations by category.
- Save favorite destinations.
- Access locally stored destination information offline.

## 🛠️ Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- Local Data Storage
- AsyncStorage

## 📱 Screens

1. Home
2. Explore Destinations
3. Destination Details
4. Favorites
5. Add Destination
6. Profile / About

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bawanioshadi/ExploreLanka.git
```

### 2. Navigate to the project folder

```bash
cd ExploreLanka
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npx expo start
```

## 📂 Project Purpose

This project is developed as an individual React Native application for an academic assignment. Its main objective is to provide an offline travel guide for exploring tourist destinations in Sri Lanka.
